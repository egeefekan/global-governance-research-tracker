# Global Governance Research Tracker

This is a beginner data analysis project about global governance indicators.

## Goal

The goal of this project is to learn Python, data analysis, and basic visualization by comparing countries using simple governance-related data.

## What I will learn

- Basic Python
- CSV files
- Data analysis
- Simple charts
- GitHub project structure

## Current Status

This project is in the beginner stage.

## Dataset

The first version uses a small sample dataset created for learning purposes. Future versions will use official public datasets.

Current indicators:
- GDP per capita
- Democracy score
- Corruption perception score
- Internet penetration

Dataset file:
`data/sample_governance_data.csv`

## Version

Current version: 0.1

This version focuses on:
- Creating a simple project structure
- Adding a sample CSV dataset
- Loading data with pandas
- Sorting countries by selected indicators
- Creating basic bar charts
- Writing early learning observations

## Notebook

The first analysis notebook is available here:

`notebooks/governance_analysis.ipynb`

It includes:
- Loading the CSV dataset with pandas
- Sorting countries by selected indicators
- Creating basic bar charts
- Writing early observations about the sample data

## How to Run

You can open the notebook in Google Colab:

1. Go to Google Colab
2. Click `File > Open notebook`
3. Select the `GitHub` tab
4. Paste this repository link
5. Open `notebooks/governance_analysis.ipynb`
6. Run the cells from top to bottom

To run locally, install the required libraries:

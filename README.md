# Global Governance Research Tracker

This is a beginner data analysis project about global governance indicators.

## Goal

The goal of this project is to learn Python, data analysis, and basic visualization by comparing countries using simple governance-related data.

## What I will learn

- Basic Python
- CSV files
- Data analysis
- Simple charts
- GitHub project structure

## Current Status

This project is in the beginner stage.

## Dataset

The first version uses a small sample dataset created for learning purposes. Future versions will use official public datasets.

Current indicators:
- GDP per capita
- Democracy score
- Corruption perception score
- Internet penetration

Dataset file:
`data/sample_governance_data.csv`
